# Ground-truth notes (corpus generator, decision 5)

The corpus is `corpus/generate_faxes.py --seed 42 --count 60`. The ground truth is `corpus/out/ground_truth.json`.

The committed extraction run (`evals/extraction_eval.json`, Claude, 60 faxes) was recorded on the pages and the truth **before** this fix. Its per-field truth matches the pre-fix generator exactly (base commit `3914b53`).

## Decisions

- **Laterality follows the referral, in this order:**
  1. A study whose name states a side takes it, so 77066 is `bilateral`.
  2. A side-specific study takes the side its ICD-10 codes name. All the catalog's codes are right-sided, so these are `right`.
  3. Only if the codes name no side does the random draw decide.
  4. Every other study is `n/a`.
- **Address belongs in the truth only when the page prints it.** More generally: a Referral field that the template does not print is `null` in the truth. So a model that correctly says "not on the page" is scored right, and one that invents an address is scored wrong. The rule is enforced by the boxes: a field has a truth value if and only if it has a box (`tests/test_corpus_truth.py`).
- **The RNG stream is preserved.** The laterality fix still makes the original random draw, in the same order, and then overrides the value. So every other value is byte-identical to the pre-fix truth, and every page whose print did not change is pixel-identical: 50 of 60 pages. This is proved against the artifact's recorded truth (1,270 values) and the pre-fix page fingerprint (`tests/test_corpus_truth.py`).
- **How boxes are recorded now:**
  1. Templates draw each value through `Sheet.text()`, tagged with its field name, so a value is boxed where it was drawn, not wherever its text recurs.
  2. Each field's ink region is painted into a label map.
  3. The map is pushed through the page's own skew and downscale (`degrade()` returns that `warp`, nearest-neighbour), and each label's bounding box becomes the field's box.
  4. The format is unchanged: `{field: {page, left, top, width, height}}`, normalised 0–1 after skew, on the last page (after a cover sheet).
  5. `tests/test_corpus_boxes_geometry.py` checks boxes against the ink of the real degraded page at the largest skew every level allows.
- **`modality` stays in the truth rows** (it is not a Referral field) but no longer gets a box.

## What changed

The full list is `evals/gt_changes.json`, generated by `python -m evals.gt_changes`:
- 45 of 60 files changed: 40 `patient_address` values became null, and 10 `laterality` values changed.
- Only the 10 laterality faxes were reprinted. Every changed laterality is printed on its page, so the replayed prediction for that field is stale on those 10 pages (`replay_stale_fields`).

**Effect on the committed extraction numbers** (same predictions, fixed truth):
- address goes from 20/60 to 60/60;
- on the 50 unchanged pages, laterality is 50/50. 040 and 058, the artifact's only two laterality misses, were "wrong" only against the defective truth, and both pages are now reprinted.
- The 10 reprinted pages need a fresh extraction before they can be scored against the fixed truth.

**The v1-vs-v2 benchmark** (`evals/benchmark_v1_v2.json`) scores every fax against the truth of the page the model actually saw (`truth_version: as_printed`): the fixed truth, except that reprinted fields keep their old printed value. It also reports false approvals under the pure pre-fix and pure post-fix truth:
- referral_040's false approval is the model answering `bilateral` on a page that printed `n/a`.
- It is caused by defect 1 and is expected to disappear on re-extraction.


**After the re-run:**
- The artifact's truth is the fixed truth, and the replay engine serves predictions read off the fixed pages.
- `as_printed`, `pre_fix` and `post_fix` then coincide for new runs.
- `evals/gt_changes.json` and `tests/test_corpus_truth.py` describe the transition from the old artifact. Re-baseline them, or keep the old artifact alongside, so the pre-fix comparison stays checkable.
- **Expected:** referral_040's false approval goes away. The laterality and address field accuracies reflect the model rather than the generator.
